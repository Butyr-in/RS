\# 🃏 Poker Analytics



Анализ покерных раздач из файлов конвертера.



\## 📊 Возможности



\- 📤 Загрузка файлов .txt через drag-and-drop

\- 💾 Хранение данных в IndexedDB

\- 👤 Автоматическое определение игрока

\- 🎯 Фильтрация по лимитам

\- 📈 График кривой капитала

\- 🎯 Распределение по лимитам

\- 👥 Топ оппонентов по выигрышу

\- 📋 Таблица с последними раздачами

\- 🌙/☀️ Темная и светлая тема

\- 📱 Адаптивный дизайн



\## 🚀 Использование



1\. Откройте `index.html` в браузере

2\. Нажмите "📤 Загрузить"

3\. Перетащите файлы .txt или выберите через диалог

4\. Дождитесь обработки

5\. Выберите игрока из списка

6\. Анализируйте статистику!

\## 📝 Формат данных



Файл .txt должен быть в формате конвертера:

gamecode;startTime;endTime;limit;player1:result;player2:result;...



text



Пример:

12460108315;00:44:28;00:49:04;NL10;mcwhahoo:€0.00;aleksmosin:€0.00;cHILLboYY:+€0.20;GNKTABACCO:€0.00



text



\## 🎯 Что можно анализировать



\- \*\*Количество рук\*\* - общее и по лимитам

\- \*\*Результат\*\* - общий выигрыш/проигрыш

\- \*\*BB/100\*\* - средневзвешенный показатель

\- \*\*Время игры\*\* - общее время

\- \*\*Оппоненты\*\* - топ по выигрышу/проигрышу

\- \*\*Динамика\*\* - кривая капитала
